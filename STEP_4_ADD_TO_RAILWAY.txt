1. Click "Variables" tab:

   ┌─────────────────────────────────────────────────────────┐

   │                                                         │
   │ ⚠️ IMPORTANT: Type this EXACTLY as shown above!        │

   │    - Underscores in the right places                   │
   └─────────────────────────────────────────────────────────┘

   ┌─────────────────────────────────────────────────────────┐

───────────────────────────────────────────────────────────────
Part C: Wait for Redeploy (2-3 minutes)
───────────────────────────────────────────────────────────────

1. Railway will automatically redeploy:
   → Adding a variable triggers automatic redeploy
   → You'll see a notification

2. Check deployment status:
   → Click "Deployments" tab (left sidebar)
   → Look at the latest deployment
   → Status should change: Building → Deploying → Success

3. Wait until status = "Success"
   → Usually takes 2-3 minutes
   → Don't close the browser

4. Check logs (OPTIONAL but recommended):
   → Click on the latest deployment
   → Click "View Logs"
   → Look for this message:
     "✅ YouTube cookies loaded from environment variable"
   → If you see this, PERFECT!

TROUBLESHOOTING:

❌ Still getting "Age-restricted video" error?

Check 1: Variable name is EXACTLY correct?
   → Go to Railway → Variables
   → Name should be: YOUTUBE_COOKIES_BASE64
   → Check spelling, capitals, underscores

Check 2: Did you paste the ENTIRE string?
   → Value should be 5000+ characters
   → No spaces at start/end
   → Starts with something like: IyBOZXRzY2FwZSBI...

Check 3: Deployment succeeded?
   → Go to Deployments tab
   → Latest deployment shows "Success"?
   → If "Failed", check logs for errors

Check 4: Cookies are fresh?
   → YouTube cookies expire
   → Try exporting fresh cookies
   → Logout from YouTube → Login → Export again

Check 5: Correct YouTube account?
   → Account must be 18+ verified
   → Must be able to view age-restricted videos
   → Try watching an age-restricted video on YouTube first

STILL NOT WORKING?

1. Check Railway logs:
