🎯 ERROR HANDLING EXAMPLES

HTTP 429 (Rate Limiting):
User sees: "YouTube is rate limiting requests. Please wait a few minutes."
Instead of: "ERROR 429: Too Many Requests"

Login Required:
User sees: "This video requires authentication or has bot protection."
Instead of: "Sign in to confirm you're not a bot"

Private Video:
User sees: "This video is private and cannot be accessed."
Instead of: "DownloadError: Private video"

Network Error (Auto-Retry):
Attempt 1: Fails → Wait 1s → Retry
Attempt 2: Fails → Wait 2s → Retry
Attempt 3: Fails → Wait 4s → Retry
Attempt 4: Fails → Return error
