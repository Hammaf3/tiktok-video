STEP 3: Convert to Base64 (3 minutes)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

A. Open PowerShell:
   → Press Windows Key + X
   → Click "Windows PowerShell"

B. Run these commands (copy-paste one by one):

cd "C:\Users\Faraz\Downloads"

Rename-Item "youtube.com_cookies.txt" "youtube_cookies.txt"

$content = Get-Content youtube_cookies.txt -Raw; $bytes = [System.Text.Encoding]::UTF8.GetBytes($content); $encoded = [Convert]::ToBase64String($bytes); $encoded | Out-File "youtube_cookies_base64.txt"; Write-Host "COPY THIS STRING:" -ForegroundColor Green; Write-Host $encoded

C. Copy the output:
   → A VERY LONG string will appear (5000+ characters)
   → Select all (CTRL+A)
   → Copy (CTRL+C)
   → Or open: youtube_cookies_base64.txt and copy from there
